# Projeto_Real_Dashboards_Power-BI_Controle_Operacional_Produtividade_Documental
Projeto real em Power BI aplicado à gestão documental e digitalização, com dashboards operacionais para monitoramento de produtividade, controle de processos e apoio à tomada de decisão, utilizando Power Query, modelagem de dados e KPIs estratégicos.
